# 链安智御（ChainWise Guard）

面向银行大模型生产应用的全链路安全管控平台（三人比赛项目）。

## 技术栈

- 后端：Go（Gin / GORM）
- 链上：FISCO BCOS（Solidity）
- 前端 / AI：FastAPI（Qwen2）、Vue 3（ECharts）

## 目录结构

```
backend/    Go 后端服务（cmd、internal/api、config 等）
chain/      链上合约（Solidity contracts）
docs/       文档（后续补充）
```
